Create a resources/css/variables.css file defining all brand colors, spacing tokens, shadow levels, and border-radius values as CSS custom properties (--color-primary, --shadow-authority, etc.). Import this into the Vite pipeline so all components consume tokens, not hardcoded values.

Create Blade components for: x-button (primary/secondary/ghost variants), x-badge, x-card, x-section-header, and x-alert. All existing inline UI patterns across pages should be refactored to use these components to enforce visual consistency.

📱 RESPONSIVE & ACCESSIBILITY
TASK-016 — Mobile Navigation Overhaul
Replace any existing mobile menu with a full-screen slide-over drawer triggered by a hamburger icon. The drawer should contain all nav links, a CTA button, and close on outside tap. Use Alpine.js for state, CSS transform: translateX for animation.
TASK-017 — Accessibility Audit & Fixes
Across all pages: add aria-label to all icon-only buttons, ensure all form inputs have associated <label> elements, verify color contrast ratios meet WCAG AA (especially slate #475569 on white), add :focus-visible outlines to all interactive elements, and add alt text to all images.

✨ POLISH & MICRO-INTERACTIONS
TASK-018 — Add Page Load Animations
On public pages, add staggered fade-up entrance animations to hero headlines, subheadings, and CTAs using CSS @keyframes with animation-delay increments (0ms, 100ms, 200ms). Keep animations under 400ms. Respect prefers-reduced-motion.
TASK-019 — Improve Button & CTA States
Audit every button and CTA across the site. Ensure all have: a defined hover state (darkened background or scale), an active/pressed state, a loading spinner state (for form submissions), and consistent padding/sizing. Buttons should never look flat or unclickable.
TASK-020 — Add a Cookie Consent Banner
Implement a bottom-fixed cookie consent bar with: a short message, "Accept" and "Manage Preferences" buttons, and Alpine.js state that dismisses it on acceptance and stores the preference in localStorage. Style it in dark navy with white text to match the brand.
